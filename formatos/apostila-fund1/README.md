# Apostila editorial — Fundamental I

Formato declarativo para páginas verticais de apostila destinadas aos anos
iniciais. Os prompts são autocontidos e preservados pelo renderizador `texto`.

O formato prioriza texto curto, hierarquia ampla, ilustrações concretas e
continuidade visual entre capa e páginas internas. A direção de cada disciplina
continua versionada dentro do respectivo autor.
