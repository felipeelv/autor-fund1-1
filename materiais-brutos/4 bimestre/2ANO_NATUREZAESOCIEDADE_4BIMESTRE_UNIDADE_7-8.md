### **🦴 A grande divisão: Vertebrados e Invertebrados**

A primeira pergunta que os cientistas fazem é: **esse animal tem coluna vertebral?**

*\[Ilustração: Raio-X de cachorro mostrando coluna vertebral ao lado de uma borboleta\]*

| Grupo | O que tem | Exemplos |
| :---: | :---- | :---- |
| 🦴 **Vertebrados** | Coluna vertebral (ossinhos nas costas) | Cachorro, peixe, sapo, cobra, galinha |
| 🐛 **Invertebrados** | Não tem coluna vertebral | Formiga, aranha, minhoca, água-viva |

**💡 Você sabia?**  
Mais de **95%** dos animais do mundo são invertebrados\! Os vertebrados são minoria, mas são os que mais conhecemos.

### **🦁 Os 5 grupos de vertebrados**

Os cientistas dividem os vertebrados em **5 grupos**. Vamos conhecer cada um em detalhes\!

*\[Ilustração: Os 5 grupos com um representante de cada\]*

---

#### **🐕 Grupo 1: Mamíferos**

Os mamíferos são animais que **amamentam** seus filhotes\!

| Característica | Descrição |
| :---: | :---- |
| 🍼 **Amamentação** | Filhotes mamam leite da mãe. |
| 🧥 **Cobertura** | Corpo coberto de pelos. |
| 🌡️ **Temperatura** | Sangue quente (controlam a própria temperatura). |
| 🫁 **Respiração** | Respiram por pulmões. |
| 🤰 **Nascimento** | Maioria nasce da barriga da mãe (vivíparos). |

**Mamíferos especiais:**

| Animal | O que tem de especial |
| :---: | :---- |
| 🦇 **Morcego** | Único mamífero que voa de verdade\! |
| 🐋 **Baleia** | Mamífero que vive no mar\! |
| 🦔 **Ornitorrinco** | Mamífero que bota ovos\! |
| 🦘 **Canguru** | Carrega o filhote na bolsa\! |

*\[Ilustração: Mamíferos variados \- cachorro, baleia, morcego, canguru\]*

---

#### **🐦 Grupo 2: Aves**

As aves são os animais com **penas**\!

| Característica | Descrição |
| :---: | :---- |
| 🪶 **Cobertura** | Corpo coberto de penas |
| 🥚 **Nascimento** | Nascem de ovos (ovíparos) |
| 🌡️ **Temperatura** | Sangue quente |
| 🦴 **Ossos** | Ossos ocos (leves para voar) |
| 🫁 **Respiração** | Pulmões muito eficientes |

**Aves que não voam:**

| Ave | Por que não voa |
| :---: | :---- |
| 🐧 **Pinguim** | Asas viraram nadadeiras |
| 🦃 **Avestruz** | Muito pesada, mas corre muito\! |
| 🥝 **Kiwi** | Asas muito pequenas |

*\[Ilustração: Aves variadas \- papagaio, pinguim, avestruz, beija-flor\]*

---

#### **🐟 Grupo 3: Peixes**

Os peixes são vertebrados que vivem **só na água**\!

| Característica | Descrição |
| :---: | :---- |
| 🐠 **Cobertura** | Corpo coberto de escamas |
| 🫧 **Respiração** | Respiram por brânquias (tiram oxigênio da água) |
| 🥚 **Nascimento** | Maioria nasce de ovos |
| 🌡️ **Temperatura** | Sangue frio |
| 🏊 **Locomoção** | Nadam com nadadeiras e cauda |

**Tipos de peixes:**

| Tipo | Características | Exemplos |
| :---: | :---- | :---- |
| 🦈 **Cartilaginosos** | Esqueleto de cartilagem (mole) | Tubarão, arraia |
| 🐟 **Ósseos** | Esqueleto de osso (duro) | Tilápia, sardinha, peixe-palhaço |

**No 3º bimestre, você aprendeu sobre a água\!**

Os peixes respiram o oxigênio que está **dissolvido na água**. Por isso, água poluída mata os peixes \- tem menos oxigênio\!

*\[Ilustração: Peixes em aquário, mostrando brânquias\]*

---

#### **🐸 Grupo 4: Anfíbios**

Os anfíbios vivem **parte na água, parte na terra**\!

O nome "anfíbio" significa "duas vidas" \- porque eles têm uma vida aquática (quando filhotes) e uma vida terrestre (quando adultos).

| Característica | Descrição |
| :---: | :---- |
| 💧 **Pele** | Lisa, fina e úmida (precisa ficar molhada\!) |
| 🥚 **Nascimento** | Ovos na água |
| 🌡️ **Temperatura** | Sangue frio |
| 🔄 **Transformação** | Passam por metamorfose |
| 🫁 **Respiração** | Filhotes: brânquias / Adultos: pulmões e pele |

**Exemplos de anfíbios:**

- 🐸 Sapo  
- 🐸 Rã  
- 🐸 Perereca  
- 🦎 Salamandra

**💡 Diferença entre sapo, rã e perereca:**

| Animal | Pele | Onde vive mais |
| :---: | :---: | :---- |
| 🐸 **Sapo** | Rugosa, com verrugas | Terra |
| 🐸 **Rã** | Lisa e úmida | Perto da água |
| 🐸 **Perereca** | Lisa, dedos com ventosas | Árvores |

*\[Ilustração: Sapo, rã e perereca lado a lado com diferenças destacadas\]*

---

#### **🐍 Grupo 5: Répteis**

Os répteis são vertebrados com **escamas secas**\!

| Característica | Descrição |
| :---: | :---- |
| 🦎 **Cobertura** | Escamas secas e duras |
| 🥚 **Nascimento** | Maioria bota ovos com casca |
| 🌡️ **Temperatura** | Sangue frio (precisam tomar sol) |
| 🫁 **Respiração** | Pulmões |
| 🦴 **Pele** | Alguns trocam de pele (como a cobra) |

**Grupos de répteis:**

| Grupo | Exemplos |
| :---: | :---- |
| 🐍 **Serpentes** | Cobra, jiboia, cascavel |
| 🐊 **Crocodilianos** | Jacaré, crocodilo |
| 🐢 **Quelônios** | Tartaruga, jabuti, cágado |
| 🦎 **Lagartos** | Lagarto, iguana, camaleão |

*\[Ilustração: Répteis variados \- cobra, jacaré, tartaruga, camaleão\]*

### **🐜 O mundo dos invertebrados**

Os invertebrados não têm coluna vertebral, mas são **muito diversos**\!

| Grupo | Características | Exemplos |
| :---: | :---- | :---- |

| 🦀 **Crustáceos** | Casca dura, muitas patas | Camarão, caranguejo, lagosta |

**💡 Os insetos são campeões\!**  
Os insetos são o grupo com **mais espécies** no mundo\! Existem mais tipos de besouros do que de todos os mamíferos, aves, répteis, anfíbios e peixes juntos\!

### **Metamorfose: Transformações Incríveis**

**🤔 Você sabia que alguns animais mudam completamente de forma?**

Alguns animais nascem de um jeito e se transformam em algo completamente diferente\! Isso se chama **metamorfose**.

*\[Ilustração: Lagarta se transformando em borboleta, girino se transformando em sapo\]*

---

### **🦋 A metamorfose da borboleta**

A borboleta passa por uma das transformações mais impressionantes da natureza\!

*\[Ilustração: Ciclo completo da metamorfose em 4 quadros\]*

**As 4 fases da vida da borboleta:**

| Fase | Nome | O que acontece | Duração aproximada |
| :---: | :---: | :---- | :---: |
| 1️⃣ | **Ovo** | A fêmea põe ovos nas folhas | 3 a 5 dias |
| 2️⃣ | **Larva (Lagarta)** | Come folhas sem parar, cresce muito | 2 a 4 semanas |
| 3️⃣ | **Pupa (Casulo)** | Fica imóvel, se transforma por dentro | 1 a 2 semanas |
| 4️⃣ | **Adulto (Borboleta)** | Sai do casulo com asas, voa, se reproduz | 2 a 4 semanas |

**O que muda na metamorfose:**

| Lagarta | Borboleta |
| :---: | :---: |
| Rasteja | Voa |
| Come folhas | Bebe néctar |
| Sem asas | Com asas coloridas |
| Muitas patas | 6 patas |
| Vive em plantas | Voa entre flores |

**💡 Incrível\!**  
Dentro do casulo, a lagarta se **dissolve quase completamente** e se reorganiza em borboleta\! É como se desmontasse um carrinho de Lego e montasse um avião com as mesmas peças\!

*\[Ilustração: Borboleta saindo do casulo\]*

---

### **🐸 A metamorfose do sapo**

Os anfíbios também passam por metamorfose\!

*\[Ilustração: Ciclo de vida do sapo em etapas\]*

**As fases da vida do sapo:**

| Fase | Características | Onde vive | Como respira |
| :---: | :---- | :---: | :---: |
| 🥚 **Ovos** | Bolinhas gelatinosas na água | Água | — |
| 🐟 **Girino jovem** | Parece peixinho, só cauda | Água | Brânquias |
| 🦵 **Girino com patas** | Nascem patas traseiras, depois dianteiras | Água | Brânquias |
| 🐸 **Sapinho** | Cauda some, pulmões se formam | Água e terra | Pulmões |
| 🐸 **Sapo adulto** | Sem cauda, pula, come insetos | Terra (perto de água) | Pulmões e pele |

**Comparando girino e sapo:**

| Girino | Sapo adulto |
| :---: | :---: |
| Vive só na água | Vive na terra (mas perto de água) |
| Tem cauda | Não tem cauda |
| Não tem patas | Tem 4 patas (traseiras grandes) |
| Respira por brânquias | Respira por pulmões e pele |
| Come algas e plantas | Come insetos e pequenos animais |

**Em Matemática, você está aprendendo sobre tempo\!**

- Fase de ovo: cerca de **1 semana**  
- Fase de girino: **6 a 12 semanas** (depende da espécie)  
- Vida adulta: pode viver **10 a 15 anos**\!

### **🔗 Cadeias alimentares**

As plantas são a **base** de quase todas as cadeias alimentares porque produzem seu próprio alimento (fotossíntese).

*\[Ilustração: Cadeia alimentar completa com setas\]*

---

#### **Os níveis da cadeia alimentar**

| Nível | Nome | O que faz | Exemplos |
| :---: | :---: | :---- | :---- |
| 1️⃣ | **Produtores** | Fazem seu próprio alimento | Plantas, algas |
| 2️⃣ | **Consumidores primários** | Comem plantas (herbívoros) | Coelho, gafanhoto, vaca |
| 3️⃣ | **Consumidores secundários** | Comem herbívoros (carnívoros) | Sapo, cobra pequena |
| 4️⃣ | **Consumidores terciários** | Comem outros carnívoros | Gavião, onça |
| 5️⃣ | **Decompositores** | Decompõem restos | Fungos, bactérias |

**Exemplo de cadeia alimentar:**

Capim → Gafanhoto → Sapo → Cobra → Gavião

  ↓         ↓         ↓       ↓        ↓

Produtor  Cons. 1º   Cons. 2º  Cons. 3º  Cons. 4º

*\[Ilustração: Cadeia alimentar com setas conectando os seres\]*

---

#### **Teia alimentar**

Na natureza, as cadeias se conectam formando uma **teia**\!

Um animal pode participar de várias cadeias:

- O sapo come gafanhotos, moscas e formigas.  
- O sapo é comido por cobras, gaviões e jacarés.

*\[Ilustração: Teia alimentar mostrando várias conexões\]*

**O que acontece se um elo desaparece?**

| Se desaparecer... | O que acontece |
| :---: | :---- |
| 🌿 As plantas | Herbívoros morrem de fome, e depois os carnívoros. |
| 🦗 Os gafanhotos | Sapos têm menos comida, podem diminuir. |
| 🐸 Os sapos | Cobras têm menos comida; gafanhotos aumentam muito. |
| 🦅 Os gaviões | Cobras aumentam muito. |

**💡 Tudo está conectado\!**  
Por isso é tão importante preservar todas as espécies \- cada uma tem seu papel\!

### **🏠 Ecossistema**

Todos os seres vivos de um lugar, junto com o ambiente (água, solo, ar, luz), formam um **ecossistema**.

**Exemplos de ecossistemas:**

| Ecossistema | Seres vivos | Ambiente |
| :---: | :---- | :---- |
| 🌳 **Floresta** | Árvores, animais, fungos | Solo úmido, muita chuva |
| 🏜️ **Deserto** | Cactos, lagartos, escorpiões | Areia, pouca água, muito calor |
| 🌊 **Oceano** | Peixes, algas, baleias | Água salgada |
| 🏞️ **Rio** | Peixes, plantas aquáticas | Água doce corrente |

**💡 Cada ecossistema tem seu equilíbrio\!**  
Quando algo muda (poluição, desmatamento, espécie invasora), todo o ecossistema é afetado.

### **💨 Poluição do ar**

O ar que respiramos pode estar **poluído** com fumaça e gases ruins.

**De onde vem a poluição do ar?**

| Fonte | O que libera |
| :---: | :---- |
| 🚗 **Carros e motos** | Fumaça dos escapamentos |
| 🏭 **Fábricas** | Fumaça das chaminés |
| 🔥 **Queimadas** | Fumaça e gases |
| 🛫 **Aviões** | Gases na atmosfera |

**O que a poluição do ar causa?**

- 😷 Doenças respiratórias (asma, bronquite)  
- 🌡️ Aquecimento do planeta  
- 🌧️ Chuva ácida  
- 😶‍🌫️ Dias com céu cinzento

Quanto mais árvores cortamos e mais poluição produzimos, **pior fica nosso ar**\!

*\[Ilustração: Cidade com ar poluído x cidade com ar limpo\]*

---

### **💧 Poluição da água**

A água que precisamos para viver também pode ser poluída.

**O que polui a água?**

| Poluente | De onde vem |
| :---: | :---- |
| 🏭 **Produtos químicos** | Fábricas que jogam resíduos nos rios |
| 🚽 **Esgoto** | Casas sem tratamento de esgoto |
| 🛢️ **Óleo** | Navios, carros, restaurantes |
| 🗑️ **Lixo** | Pessoas que jogam lixo nos rios |
| 🧴 **Plástico** | Embalagens que vão para o mar |

**Consequências da poluição da água:**

- 🐟 Peixes e outros animais morrem  
- 🚱 Menos água potável para beber  
- 🤢 Doenças em pessoas e animais  
- 🏖️ Praias impróprias para banho

*\[Ilustração: Rio limpo x rio poluído\]*

### **🌳 Desmatamento**

Desmatamento é a **destruição das florestas**.

**Por que desmatam?**

| Motivo | O que fazem |
| :---: | :---- |
| 🐄 **Criar gado** | Derrubam árvores para fazer pasto. |
| 🌾 **Plantar soja/milho** | Derrubam para fazer plantações. |
| 🏠 **Construir** | Derrubam para fazer cidades, estradas. |
| 🪵 **Vender madeira** | Cortam árvores para vender. |

Lembra o que as plantas fazem?

- Produzem **oxigênio.**  
- Absorvem **gás carbônico.**  
- Protegem o **solo.**  
- São **casa** de animais.  
- Regulam as **chuvas.**

**Consequências do desmatamento:**

| Problema | Por que acontece |
| :---: | :---- |
| 🦜 Animais perdem casa | Ficam sem onde viver. |
| 🌡️ Clima muda | Menos árvores, mais calor. |
| 🌧️ Menos chuva | Árvores ajudam a trazer chuva. |
| 🏜️ Solo vira deserto | Sem raízes, solo é levado pela água. |
| 💨 Ar fica pior | Menos oxigênio, mais gás carbônico. |

*\[Ilustração: Floresta sendo desmatada, animais fugindo\]*

### **🔥 Queimadas**

Queimadas são incêndios na vegetação, muitas vezes causados por humanos.

**Problemas das queimadas:**

- 🐾 Matam animais  
- 🌳 Destroem plantas  
- 💨 Poluem o ar  
- 🏠 Ameaçam comunidades  
- 🌡️ Aumentam o aquecimento global

**💡 Você sabia?**  
No Brasil, a maioria das queimadas é causada por **humanos** (para limpar terrenos), não por causas naturais.

### **🌱 Desenvolvimento sustentável**

**Desenvolvimento sustentável** é usar os recursos da natureza **sem destruí-los**, para que as próximas gerações também possam usar.

É como uma árvore frutífera:

- ❌ **Errado:** Cortar a árvore para pegar todas as frutas de uma vez  
- ✅ **Certo:** Colher as frutas sem machucar a árvore, para ela dar frutas todo ano

*\[Ilustração: Árvore sendo cuidada x árvore cortada\]*

---

### **💚 O que você pode fazer**

Mesmo sendo criança, você pode ajudar muito\!

**Em casa:**

| Ação | Como ajuda |
| :---: | :---- |
| 💡 Apagar a luz ao sair | Economiza energia |
| 🚿 Banhos rápidos | Economiza água |
| 🗑️ Separar o lixo | Facilita a reciclagem |
| 🍽️ Não desperdiçar comida | Menos lixo, menos desperdício |
| 🛍️ Usar sacola retornável | Menos plástico |

**Na escola:**

| Ação | Como ajuda |
| :---: | :---- |
| 📝 Usar os dois lados do papel | Menos árvores cortadas |
| 🗑️ Jogar lixo na lixeira certa | Reciclagem |
| 🚰 Não deixar torneira pingando | Economiza água |
| 🌱 Cuidar das plantas | Mais verde |

**Na comunidade:**

| Ação | Como ajuda |
| :---: | :---- |
| 🌳 Plantar árvores | Mais oxigênio, mais sombra |
| 🧹 Participar de mutirões | Comunidade mais limpa |
| 📢 Conversar com outros | Mais pessoas ajudando |

- Apagar luzes \= economia na conta de luz
