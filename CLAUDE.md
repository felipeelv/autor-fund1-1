# Orientação para assistentes

As instruções canônicas deste repositório estão em `AGENTS.md`.

Antes de alterar código, conteúdo, prompts ou projetos:

1. leia `AGENTS.md`;
2. leia `README.md`;
3. leia `autores/autor-teste-fund1/direcao/AUTOR.md`;
4. leia `autores/autor-teste-fund1/direcao/MEMORIA.md`.

Este projeto usa exclusivamente OpenAI `gpt-image-2` e não admite dependências
operacionais de outros repositórios.
