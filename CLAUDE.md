# Orientação para assistentes

As instruções canônicas deste repositório estão em `AGENTS.md`.

Antes de alterar código, conteúdo, prompts ou projetos:

1. leia `AGENTS.md`;
2. leia `README.md`;
3. identifique o autor em uso;
4. leia `autores/<autor>/direcao/AUTOR.md`;
5. leia `autores/<autor>/direcao/MEMORIA.md`.

Autores disponíveis:

- `autor-fund1`: Inglês do Fundamental I;
- `autor-mat3`: Matemática do 3º ano do Fundamental I.

Os projetos declaram explicitamente OpenAI `gpt-image-2` ou xAI
`grok-imagine-image-2.0`. O repositório não admite dependências operacionais de
outros repositórios.
