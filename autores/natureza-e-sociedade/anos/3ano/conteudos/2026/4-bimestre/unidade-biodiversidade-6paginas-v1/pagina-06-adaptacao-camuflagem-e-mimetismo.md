# Página 6 — Adaptação, Camuflagem e Mimetismo

Status: aguardando revisão humana.

## Intenção pedagógica

Como as espécies se ajustam ao ambiente para sobreviver.

## Conteúdo selecionado da fonte (linhas 407–475)

- as espécies não aparecem prontas! elas se adaptam ao longo de milhões
  de anos
- adaptação é quando características de uma espécie são adequadas para
  viver em um ambiente específico
- adaptações estruturais (corpo, forma): Girafa — pescoço longo, para
  alcançar folhas no topo das árvores; Pinguim — corpo hidrodinâmico, para
  nadar rápido na água; Camelo — joroba com gordura, para guardar energia
  no deserto seco
- adaptações comportamentais (o que o animal faz): Pássaros — migração,
  para fugir do frio; Urso — hibernação, para economizar energia no
  inverno; Leão — viver em grupo, para caçar juntos
- camuflagem: alguns animais têm cores/padrões que os ajudam a se
  esconder. Gafanhoto — verde como folha; Sapo — marrom como tronco;
  Onça — manchas como sombra de árvore
- mimetismo: algumas espécies enganam predadores parecendo ser outras
  coisas. Borboleta (asa) — parece rosto de coruja, predador se assusta;
  Cobra não-venenosa — parece cobra venenosa (cores), predador tem medo
- diferença importante: camuflagem é esconder-se no ambiente; mimetismo é
  parecer ser outra coisa
