# Autor `ingles`

Autor autônomo de páginas de apostila e atividades de Inglês do Fundamental I.
O acervo atual contém a sequência de cores do 1º ano e um caderno de atividades
sobre esportes e `can` para o 3º ano.

Fontes, conteúdos editoriais, direção, prompts, projetos e registros ficam
nesta pasta. O núcleo Python e as configurações reutilizáveis ficam na raiz do
repositório exclusivo. Todas as imagens são gravadas fora do repositório,
primeiro na área externa `_revisao`.
