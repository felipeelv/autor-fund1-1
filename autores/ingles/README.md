# Autor `ingles`

Autor autônomo das páginas de **conteúdo** de Inglês do Fundamental I. O par de
atividades é o autor `ingles-atividades`, que pede que o aluno faça.

O acervo atual tem a sequência de cores do 1º ano — Unidade 3, quatro páginas,
conferidas e promovidas para `aprovadas` em 18/08/2026.

Até 18/08/2026 este autor também abrigava o caderno de atividades do 3º ano.
Ele foi movido para `ingles-atividades` na separação entre conteúdo e
atividades, junto com a fonte, os prompts, o projeto e os registros.

Fontes, conteúdos editoriais, direção, prompts, projetos e registros ficam nesta
pasta. Todas as imagens são gravadas fora do repositório, primeiro na área
externa `_revisao`.
