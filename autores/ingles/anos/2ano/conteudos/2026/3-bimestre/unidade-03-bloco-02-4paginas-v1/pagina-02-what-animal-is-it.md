# WHAT ANIMAL IS IT?

## PERGUNTE E RESPONDA

Para perguntar que animal é, use:

**WHAT ANIMAL IS IT?** = Que animal é esse?

Quem responde usa **IT IS A...** = É um/uma...

## ENTENDA A CONVERSA

<!-- Visual: quatro cenas pequenas em sequência, cada uma com duas crianças
brasileiras diante de um animal do zoológico. -->

**A:** What animal is it?
**B:** It is a **lion**!

**A:** What animal is it?
**B:** It is an **elephant**!

**A:** What animal is it?
**B:** It is a **monkey**!

**A:** What animal is it?
**B:** It is a **snake**!

## ATENÇÃO

Use **AN** antes de **ELEPHANT**, porque a palavra começa com som de vogal.

- It is a lion ✅
- It is an elephant ✅

## AGORA É COM VOCÊ

Escolha um dos quatro animais e responda: **It is a(n)...**
