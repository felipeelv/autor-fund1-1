# ESTRUTURA: IT IS... (COLOR)

**IT IS...** = É... / Isto é...

*[Ilustração: objetos coloridos]*

**Exemplos:**

- The ball is **red**. (A bola é vermelha)
- The car is **blue**. (O carrinho é azul)
- The doll is **pink**. (A boneca é rosa)
- The teddy bear is **brown**. (O ursinho é marrom)
- The kite is **yellow**. (A pipa é amarela)
- The robot is **black**. (O robô é preto)

**Orientações de gestos:**

- RED: apontar para algo vermelho
- ORANGE: fazer formato de laranja

- RAINBOW VIEW: desenhar arco-íris no ar com a mão
- PINK: apontar para algo rosa
- BROWN: apontar para algo marrom (mesa, chão)
- BLACK: fechar os olhos
- WHITE: abrir os braços (luz)
- SHINING BRIGHT: dedos abertos brilhando

# WHAT COLOR IS IT?

## HORA DE CONVERSAR

Agora vamos aprender a perguntar sobre cores!

## ESTRUTURA: WHAT COLOR IS IT?

**Pergunta:** **WHAT COLOR IS IT?** = De que cor é? / Qual é a cor?

**Resposta:** **IT IS...** = É...

*[Ilustração: crianças apontando para objetos coloridos]*

**Exemplos de diálogos:**

**Diálogo 1:**

- What color is the ball?
- It is **red**.

**Diálogo 2:**

- What color is the car?
- It is **blue**.

**Diálogo 3:**

- What color is the teddy bear?
- It is **brown**.

**Diálogo 4:**

- What color is the doll?
- It is **pink**.

---

## MÚSICA: WHAT COLOR IS IT?

*(Melodia: "A Dona Aranha")*

**What color is the ball?** **What color is the ball?** **It is red, it is
red** **The ball is red!**

**What color is the car?** **What color is the car?** **It is blue, it is
blue** **The car is blue!**

**What color is the kite?** **What color is the kite?** **It is yellow, it is
yellow** **The kite is yellow!**

**What color is the bear?** **What color is the bear?** **It is brown, it is
brown** **The teddy bear is brown!**

**Orientações de gestos:**

- WHAT COLOR: dar de ombros, expressão de pergunta
- BALL: mãos em círculo
- IT IS RED: apontar para algo vermelho
- CAR: mãos no volante
- IT IS BLUE: apontar para o céu
- KITE: olhar para cima, segurar linha
- IT IS YELLOW: apontar para o sol
- BEAR: abraçar urso imaginário
- IT IS BROWN: apontar para algo marrom

## VOCÊ SABIA?

Os cães não veem todas as cores como nós! Eles veem principalmente azul e
amarelo. Para um cachorro, um brinquedo vermelho parece marrom! Mas isso não
importa - eles ainda adoram brincar!
