# PERGUNTE E RESPONDA

## WHAT COLOR IS IT?

**What color is it?** = De que cor é?

**It is...** = É...

<!-- Visual: seta de fluxo entre olhar para o objeto, perguntar e responder. -->

## DIÁLOGO-MODELO

<!-- Duas crianças brasileiras; uma aponta para uma banana. -->

**A:** What color is it?

**B:** It is yellow!

## PRÁTICA EM DUPLA

Em dupla:

1. **Aponte** para uma cor.
2. **Pergunte:** What color is it?
3. **Responda:** It is...!
4. **Troque** de papel.
