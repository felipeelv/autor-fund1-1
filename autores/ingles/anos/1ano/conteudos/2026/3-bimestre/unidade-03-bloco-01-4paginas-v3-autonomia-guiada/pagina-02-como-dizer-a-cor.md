# COMO DIZER A COR DE ALGO

## USE IT IS...

Quando você observa um objeto e quer dizer sua cor, comece a frase com
**IT IS...**

**IT IS...** = É... / Isto é...

A palavra da cor vem depois de **IT IS**.

<!-- Visual: peças de papel se encaixam como uma construção de frase. -->

**IT IS** + **RED** → **It is red.**

## OBSERVE OS EXEMPLOS

<!-- Visual: cada frase ligada ao objeto correspondente; o nome do objeto não
aparece em inglês. -->

Maçã vermelha → **It is red.**

Céu azul → **It is blue.**

Sol amarelo → **It is yellow.**

Folha verde → **It is green.**

Fruta laranja → **It is orange.**

Uvas roxas → **It is purple.**

## FAÇA ASSIM

1. Observe o objeto.
2. Descubra a cor.
3. Escolha a palavra em inglês.
4. Diga a frase completa: **It is...**
