# REVISÃO DO BLOCO

## O QUE VOCÊ APRENDEU

**FORMAS:** circle (círculo), square (quadrado), triangle (triângulo),
rectangle (retângulo).

**NÚMEROS (revisão):** one a ten (1 a 10).

## AS QUATRO FRASES DO BLOCO

<!-- Visual: quatro cartões, um por estrutura, cada um com um ícone simples. -->

**It is a** + cor + forma. → **It is a red circle.**

Número + cor + forma. → **Three red circles.**

**What is this?** → **It is a green triangle!**

**I like...** → **I like squares.**

### NÃO CONFUNDA

**What is this?** pergunta o que é um objeto.

**It is a...** responde com a cor e a forma do objeto.
