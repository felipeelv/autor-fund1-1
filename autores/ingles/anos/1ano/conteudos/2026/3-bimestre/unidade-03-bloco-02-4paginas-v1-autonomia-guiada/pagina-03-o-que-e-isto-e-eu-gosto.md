# WHAT IS THIS? + I LIKE...

## PERGUNTE O QUE É

Para perguntar o que é um objeto, use:

**WHAT IS THIS?** = O que é isto?

Quem responde observa a forma e a cor, e usa **IT IS A** + cor + forma.

<!-- Visual: pergunta → forma → resposta, ligadas por setas. -->

## ENTENDA A CONVERSA

<!-- Visual: duas crianças observando uma forma colorida. -->

**A:** What is this?

**B:** It is a red triangle!

## VEJA MAIS UM EXEMPLO

<!-- Visual: segunda cena, outra forma colorida. -->

**A:** What is this?

**B:** It is a green circle!

## USE I LIKE... COM FORMAS

Quando você quer falar de uma forma de que gosta, use:

**I LIKE...** = Eu gosto de...

I like **circles**. (Eu gosto de círculos)

I like **squares**. (Eu gosto de quadrados)

I like **triangles**. (Eu gosto de triângulos)

## CONVERSE EM DUPLA

1. Um colega aponta para uma forma colorida.
2. O outro pergunta: **What is this?**
3. O colega responde: **It is a … …!**
4. Depois, digam de qual forma vocês gostam: **I like...**

### LEMBRE-SE

A pergunta **What is this?** termina com **?**. A resposta começa com
**It is a...**
