# Página 3 — As quatro operações

Status: aguardando revisão humana.

## Intenção pedagógica

Distinguir o sentido das quatro operações e oferecer perguntas-guia para
escolher a operação adequada.

## Conteúdo selecionado da fonte

- AS QUATRO OPERAÇÕES
- Adição + — Juntar, acrescentar — Soma
- Subtração - — Tirar, diferença — Diferença
- Multiplicação × — Grupos iguais, vezes — Produto
- Divisão ÷ — Repartir, agrupar — Quociente
- ESCOLHENDO A OPERAÇÃO CORRETA
- Estou juntando ou acrescentando? Adição (+)
- Estou tirando ou comparando? Subtração (-)
- Tenho grupos iguais ou “vezes maior”? Multiplicação (×)
- Estou repartindo ou fazendo grupos? Divisão (÷)
- PASSO A PASSO
- Leia o problema com atenção.
- Identifique os dados.
- Descubra o que o problema pergunta.
- Escolha as operações necessárias.
- Resolva uma etapa de cada vez.
- Verifique se a resposta faz sentido.
